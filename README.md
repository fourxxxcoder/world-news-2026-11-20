A Python program (standard library only, with its own tiny 5x7 pixel font and PNG encoder) that draws a 1024x1024 newspaper poster summing up the world news of Friday 20 November 2026 — the ICJ's Myanmar genocide ruling, the first Trump-Xi-Putin summit in Shenzhen, Russia's strikes on Kyiv, the Riyadh missile hit, the AI sell-off, COP31, Voyager 1 at one light-day, and more (see SOURCES.md) — and writes it deterministically to /output/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
